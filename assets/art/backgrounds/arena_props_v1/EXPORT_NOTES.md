# Generated breakable props

Seven transparent 1536x1024 PNG sheets generated from PROMPTS.md using built-in image_gen, after inspecting each current arena backdrop. Each sheet has three intact/broken pairs (21 pairs total).

Real PNG alpha verified for all seven sheets, including empty space and interior gaps. Preview dark matte is not part of the sprites. Alpha-clear coverage ranges47.5–71.3%.

Use measured per-sprite rectangles in exports.json, not the prompt's equal thirds. Actual row gaps and column divisions differ, sometimes between columns or rows. Source images are preserved unchanged. Use the same uniform scale per pair and align each source baseline to the same world floor when integrating. inspect_exports.py reproduces the metadata without editing artwork.

Exact generation prompts and source image provenance are retained in generation.json. This delivery creates art assets only; runtime mapping is left for integration in the shared checkout.
